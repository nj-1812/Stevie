# To my Stevie 💕

A little love language quiz.

## Put it on GitHub Pages
1. Create a new public repository on GitHub (e.g. `to-my-stevie`).
2. Upload `index.html` (Add file → Upload files → Commit).
3. Go to **Settings → Pages**, set Source to **Deploy from a branch**, pick `main` and `/ (root)`, and Save.
4. Wait a minute, then open `https://<your-username>.github.io/to-my-stevie/`.
